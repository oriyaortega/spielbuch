# Подземелья Чёрного замка — Telegram-бот

Бот для прохождения книги-игры Д. Браславского (1991) в Telegram: кубики бросает бот,
листок путешественника он ведёт сам, решения принимает игрок.

## Запуск

0. Текста книги в репозитории нет. Соберите `data/book.json` из своего PDF
   (`pip install pymupdf`, затем
   `python build_book.py путь/к/Podzemelya_Chyornogo_zamka_1991.pdf data/book.json`).
1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и вставьте туда токен.
3. Установите зависимости и запустите:

```bash
pip install -r requirements.txt
```

```bash
python bot.py
```

### Через Docker

Нужны `data/book.json` (шаг 0, он копируется в образ) и файл `.env` с `BOT_TOKEN`. Затем:

```bash
docker compose up -d --build
```

База игроков хранится в `./data/players.db` рядом с `docker-compose.yml` и переживает пересборку контейнера.
Логи: `docker compose logs -f`, остановка: `docker compose down`.

Бот работает, пока запущен скрипт (long polling, белый IP и вебхуки не нужны).
Для работы 24/7 подойдёт любой VPS или бесплатный хостинг с Python (Railway, Fly.io, PythonAnywhere и т.п.).

## Файлы

| Файл | Что делает |
|---|---|
| `build_book.py` | PDF → `data/book.json` |
| `data/book.json` | (не в git) 617 параграфов: текст, переходы с подписями, враги, изменения характеристик, концовки. Можно править руками |
| `game.py` | правила: создание героя, бой, удача, заклятия, мешок, фляга |
| `bot.py` | Telegram-интерфейс (aiogram 3) |
| `storage.py` | сохранение игроков в `data/players.db` (SQLite) |
| `test_game.py` | тесты: `python -m pytest -q` |

Пересборка книги:

```bash
python build_book.py путь/к/Podzemelya_Chyornogo_zamka_1991.pdf data/book.json
```

## Что умеет бот

- Создание героя по правилам (1к6+6 / 2к6+12 / 1к6+6), переброс, выбор до 10 заклятий.
- Кнопки переходов с подписями из текста. Кнопки со ✨ (например «Плавания → 372») сами тратят заклятие и не дают пройти без него.
- Кнопки «Применить −2 ВЫН» для изменений характеристик, найденных в тексте.
- Бой по правилам книги: один враг, несколько по очереди или несколько разом (выбор цели каждый раунд),
  модификаторы СИЛЫ УДАРА ±1 (для заклятий Силы/Слабости и прочих бонусов), заклятие Копии, бегство (−2 ВЫН).
- Проверка удачи, фляга (2 глотка по +2), Исцеление (+8), мешок на 7 предметов, золото.
- Заметки и ручной переход `/go N` для скрытых ходов книги («прибавьте 60 к номеру параграфа…»).
- Прогресс сохраняется, после перезапуска бота игра продолжается.

Команды: `/start`, `/sheet`, `/bag`, `/para`, `/go N`, `/note текст`, `/rules`, `/new`, `/help`.

## Об авторских правах

Текст книги принадлежит правообладателю, поэтому `data/book.json` не хранится в репозитории.
Для публичного бота нужно разрешение правообладателя.
